# Django Job Portal

A full-stack job portal built with Django to demonstrate authentication, job posting, job discovery, applications, database relationships, and role-based workflows.

## Planned Features
- Candidate and recruiter accounts
- Recruiter job posting and management
- Job search and filtering
- Candidate applications
- Application status tracking
- Django admin dashboard
- REST APIs
- SQLite for development with PostgreSQL-ready configuration

## Tech Stack
Python, Django, Django REST Framework, SQLite/PostgreSQL, HTML, CSS, JavaScript

## Project Goal
Build a realistic recruitment platform while demonstrating backend, database, API, and full-stack development skills.
